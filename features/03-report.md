# Feature 03: dowser сохраняет отчёт в JSON (F6)

- **Способность:** результаты сессии сохраняются в JSON-файл.
- **Демо:** `dowser scan --scope ... --out report.json` → файл валиден, `jq`
  показывает узлы, сервисы и находки по severity.

## Контракты

Межмодульные: `report.WriteJSON`, методы чтения `store` для `report`.

Решить до кода:

- **`report` получает только `[]core.Finding`.** В находке есть `AssetRef` и
  `ServiceRef`, но не адрес и не порт, поэтому в отчёте не будет
  `192.168.1.10:22`. Варианты: передавать ещё `[]Asset` и `[]Service`, или
  отдельную структуру «результат сессии». Это изменение межмодульного контракта.
- **Методы чтения `store` для `report` не описаны.** Нужен как минимум
  `Findings()`. Где объявлен интерфейс: у потребителя (`cli`) или в `core`.
- Локальное: как `Severity` и `Category` выглядят в JSON (строкой или
  числом), структура документа (плоский список или вложенность узел → сервис
  → находки).
