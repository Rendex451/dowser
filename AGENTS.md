# dowser

Этот проект разрабатывается по модели **kickoff → feature → task**.
В начале каждой рабочей сессии вызови скилл командой /kft-model и дальше
следуй ему.

Ключевое: карту модулей и интерфейсы задаёт только автор проекта; агент
предлагает, но не меняет их сам. Исполнителя по каждой task выбирает автор.

- Архитектура и межмодульные контракты: ARCHITECTURE.md
- Текущая feature: features/<NN-name>.md
- Бэклог улучшений: improvements.md — заводится после финального ревью среза,
  не раньше; по ходу работы не трогать
